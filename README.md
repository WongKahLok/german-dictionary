# German Dictionary

A single-file study reference for NTU German Course **LG5001** and **LG5002**.
=
**2,942 vocabulary entries · 25 grammar topics**

- Search German or English, accents optional (`nachte` finds `Nächte`)
=- Every verb conjugated across Präsens, Präteritum and Perfekt; sort by separable / regular / irregular
- Filter by gender, word class or lesson; Practice mode hides articles and plurals for self-testing
- 1,631 entries carry an example sentence
- Grammar side covers word order, cases, prepositions, modals, the past and more

Built from *Schritte international NEU 1+2, Glossar Deutsch–Englisch* (Hueber, 2018),
*Unregelmäßige Verben A1–B1* (Klett), and the LG5001 / LG5002 Grammar Notes (Monica Brunen).
Example sentences from [de.wiktionary.org](https://de.wiktionary.org), CC BY-SA 4.0.
